## 🌟 Présentation

Portfolio officiel conçu avec une esthétique **« Terminal Premium »**, un mode sombre permanent soigné et des animations fluides. Il met en valeur mes compétences full-stack, mes projets réels déployés en production et mon parcours professionnel.

### ✨ Fonctionnalités clés :
- 🌓 **Mode Sombre Exclusif & Permanent** : Expérience visuelle immersive haute performance avec palette néon lime (`#C6F135`) et contraste profond (`#0B0E14`).
- 🌍 **Bilingue Temps Réel (Français / Anglais)** : Bascule instantanée du contenu et synchronisation dynamique des CV téléchargeables (`cv-fr.pdf` / `cv-en.pdf`).
- 📁 **Vitrine de Projets avec Études de Cas Détaillées** :
  - **Délice Express** : Application web e-commerce de restauration rapide ([Live](https://deliceexpress.pythonanywhere.com))
  - **ArchivEx** : Plateforme éducative centralisant les annales d'examen et fiches de révision ([Live](https://archivex.online))
  - **iMMoLink** : Plateforme immobilière nationale pour les 12 départements du Bénin ([Live](https://immolink.pythonanywhere.com))
  - **Landing Pages** : Sites vitrines haute conversion pour [Aurelia Hotel](https://hotel-aurelia.web.app) & [Mel House](https://melhouse.netlify.app)
  - **Cookly** : Application mobile de cuisine et recettes intelligentes (Ionic / Angular)
  - **Pharma-Gest** & **Achatoo** : Systèmes de gestion de pharmacie et d'achats groupés
- 📱 **100% Responsive & Mobile-First** : Navigation fluide sur smartphone, tablette et écran large.
- ⚡ **Animations Micro-interactives** : Anime.js pour les apparitions au défilement et transitions subtiles.
- 📬 **Formulaire de Contact Connecté** : Support d'EmailJS et lien WhatsApp direct.

## 🛠️ Stack Technique

- **Frontend :** HTML5 sémantique, Tailwind CSS, Vanilla JavaScript (ES6+), Anime.js
- **Assets :** Galerie de captures d'écran d'applications réelles nettoyées et optimisées
- **Hébergement & Déploiement :** Google Firebase Hosting
- **Outils & Versioning :** Git, GitHub, Firebase CLI

---

## 🚀 Déploiement

Le site est déployé automatiquement sur Firebase Hosting :

```bash
# Tester en local
cd portfolio
# Ouvrir index.html dans un navigateur ou via un serveur local

# Déployer sur Firebase
firebase deploy --only hosting
```
